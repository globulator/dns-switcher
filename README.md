# DNS Switcher (Linux & Windows)

Кроссплатформенный инструмент для быстрого переключения DNS-серверов с целью обхода блокировок, измерения реальной задержки ответа, безопасного переключения и возврата к автоматическим сетевым настройкам.

* **Linux**: нативное расширение для верхней панели **GNOME Shell**.
* **Windows**: быстрое приложение в **системном трее (Notification Area)**.

---

## Возможности и интерфейс

1. **Поиск и сортировка**:
   - Строка поиска `🔍 Поиск...` для мгновенной фильтрации серверов по имени на лету.
   - Кнопка переключения сортировки (по задержке или по алфавиту).
2. **Вкладки по категориям**:
   - Антиблокировочные (VPN-иконка)
   - Защитные (щит)
   - Глобальные (глобус)
   - Национальные (флаг)
3. **Список DNS-провайдеров**:
   - **Радио-индикатор**: неактивные строки отображаются с тонким контуром круга, активный сервер — синим кругом с точкой.
   - **Подсветка строк**: активно выбранный DNS ярко подсвечен плашкой с контуром.
   - **Протокольные бейджи**: индикаторы `UDP`, `DoT` или `DoH` рядом с именем сервера.
   - **Измерение задержки**:
     - При проверке отображается анимация точек (`.` → `..` → `...`).
     - Замер выполняется в потоковом режиме параллельно для всех серверов.
     - Зелёный цвет (например, `23 ms`) при успешном DNS-запросе и подтверждённой доступности цели.
     - Красный цвет (`не отвечает`, `не найден`, `недоступен`, `регион недоступен`) при ошибке, фильтрации или таймауте.
   - **Удаление**: кнопка корзины справа от строки удаляет сервер из категории.
4. **DNS по умолчанию**:
   - Нижняя строка со значком проводной сети.
   - Возвращает исходные сетевые настройки текущего профиля (DHCP/автоматически).
5. **Нижняя панель управления**:
   - Кнопка `+`: добавление собственного сервера с выбором категории.
   - **Выбор цели проверки**: выпадающее меню по центру (`🌐 google.com ▾`):
     - Позволяет выбирать, на каком домене проверять задержку (например, `google.com`, `youtube.com`, `rutracker.org`, `discord.com`).
     - Возможность добавлять новые целевые сервисы или удалять существующие.
   - Кнопка `↻`: принудительное обновление проверки задержки.
   - Кнопка `♡`: поддержка автора проекта на [Boosty](https://boosty.to/globulator/donate).

## Архитектура проекта

Проект спроектирован по модульному принципу без дублирования бизнес-логики:

```text
dns-switcher/
├── core/                        # Единое ядро (100% общий код)
│   ├── engine.py                # Замеры задержки UDP/DoT/DoH, TLS-сокеты, проверка bypass
│   ├── storage.py               # Пресеты, категории, кэш, потокобезопасное хранилище
│   ├── adapter.py               # Абстрактный интерфейс сетевого адаптера
│   └── cli.py                   # Единый CLI/JSON интерфейс
│
├── platforms/                   # Платформо-зависимые сетевые команды
│   ├── linux.py                 # NetworkManager (nmcli) и systemd-resolved (resolvectl)
│   └── windows.py               # PowerShell (Set-DnsClientServerAddress) и Clear-DnsClientCache
│
├── ui/                          # Интерфейсы пользователей
│   └── tray/                    # Кроссплатформенный системный трей (PyQt6/PySide6)
│       ├── app.py               # Графический интерфейс трея
│       ├── updater.py           # Проверка обновлений через GitHub Releases
│       ├── build_exe.py         # Сборка автономного .exe через PyInstaller
│       └── build.bat            # Скрипт сборки под Windows
│
├── extension.js                 # GNOME Shell Extension
├── metadata.json                # Манифест расширения GNOME
├── stylesheet.css               # Стили GNOME Shell
├── dns_backend.py               # Точка входа для GNOME Shell
├── main.py                      # Универсальная точка входа CLI и GUI
└── pack_gnome_extension.sh      # Скрипт упаковки расширения GNOME в zip
```

## Установка и использование

### Linux (GNOME Shell)

1. Подключение расширения через символическую ссылку:
   ```bash
   mkdir -p ~/.local/share/gnome-shell/extensions
   ln -sfn ~/Applications/dns-switcher ~/.local/share/gnome-shell/extensions/dns-switcher@globulator
   ```
2. Включение расширения:
   ```bash
   gnome-extensions enable dns-switcher@globulator
   ```

Либо соберите архив для установки через GNOME Extensions:
```bash
./pack_gnome_extension.sh
```

### Windows

1. Скачайте готовый `DNS-Switcher.exe` из раздела [Releases](https://github.com/globulator/dns-switcher/releases).
2. Запустите файл от имени Администратора (требуется Windows для изменения параметров DNS сетевого адаптера).

#### Сборка из исходников на Windows:
```cmd
pip install -r requirements.txt
python ui/tray/build_exe.py
```
Готовый файл будет в `dist/DNS-Switcher.exe`.

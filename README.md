# DNS Switcher для GNOME Shell (Ubuntu 26.04)

Расширение для верхней панели GNOME (индикатор с выпадающим меню) для быстрого переключения DNS-серверов с целью обхода блокировок, измерения реальной задержки ответа, безопасного переключения и возврата к автоматическим сетевым настройкам.

---

## Возможности и интерфейс

1. **Поиск и сортировка**:
   - Строка поиска `🔍 Поиск...` для мгновенной фильтрации серверов по имени на лету.
   - Кнопка переключения сортировки (по задержке или по алфавиту).
2. **Вкладки по категориям**:
   - Антиблокировочные (VPN-иконка)
   - Защитные (щит)
   - Глобальные (глобус)
   - Национальные (флаг)
3. **Список DNS-провайдеров**:
   - **Радио-индикатор**: неактивные строки отображаются с тонким контуром круга, активный сервер — синим кругом с точкой.
   - **Подсветка строк**:
     - **Фактически активный DNS**: ярко подсвечен плашкой с контуром (`rgba(255, 255, 255, 0.16)`).
     - **Наведение мыши**: мягкая подсветка строки (`:hover`).
   - **Протокольные бейджи**: индикаторы `UDP`, `DoT` или `DoH` рядом с именем сервера.
   - **Измерение задержки**:
     - При проверке отображается анимация точек (`.` → `..` → `...`).
     - Замер выполняется в потоковом режиме параллельно для всех серверов.
     - Зелёный цвет (например, `23 ms`) при успешном DNS-запросе и подтверждённой доступности цели.
     - Красный цвет (`не отвечает`, `не найден`, `недоступен`, `регион недоступен`) при ошибке, фильтрации или таймауте.
   - **Удаление**: кнопка корзины справа от строки удаляет сервер из категории.
4. **DNS по умолчанию**:
   - Нижняя строка со значком проводной сети.
   - Возвращает исходные сетевые настройки текущего профиля NetworkManager.
5. **Нижняя панель управления**:
   - Кнопка `+`: открывает строку для добавления сервера с выбором категории (иконка слева от галочки) и кнопкой сохранения `✔`.
   - **Выбор цели проверки**: выпадающее меню по центру (`🌐 google.com ▾`):
     - Позволяет выбирать, на каком домене проверять задержку (например, `google.com`, `youtube.com`, `rutracker.org`, `discord.com`).
     - Возможность добавлять новые целевые сервисы или удалять существующие.
   - Кнопка `↻`: принудительное обновление проверки задержки.

## Поддерживаемые протоколы

- **UDP (порт 53)**: стандартные DNS-запросы. Поддерживаются и применяются в NetworkManager.
- **DoT (DNS-over-TLS, порт 853)**: шифрованные DNS-запросы. Поддерживаются и применяются через `systemd-resolved` в режиме оппортунистического TLS (`connection.dns-over-tls 1`) с указанием SNI (`ip#hostname`).
- **DoH (DNS-over-HTTPS, порт 443)**: поддерживается в режиме замера задержки. Отображается оранжевым бейджем `DoH`. Применение системного DoH через NetworkManager/systemd-resolved не поддерживается на уровне ОС, поэтому при попытке применить такой сервер выдаётся предупреждение.

## Архитектура и безопасность

- **Безопасное переключение и автооткат**:
  - Перед первой модификацией снимается снимок исходных параметров профиля (`ipv4.dns`, `ipv4.ignore-auto-dns`, `ipv4.dns-priority`, `connection.dns-over-tls`).
  - После применения нового сервера выполняется контрольный DNS-запрос (`resolvectl query`). Если сервер не отвечает, настройки немедленно и автоматически откатываются назад к исходным.
  - Применяется всегда свежая проба (не устаревший кэш).
- **Интеграция с NetworkManager**:
  - Настройки применяются к активному физическому сетевому подключению (Ethernet/Wi-Fi), исключая VPN, WireGuard, мосты и loopback.
  - Не модифицирует `/etc/resolv.conf` напрямую.
  - После применения автоматически очищается системный кэш резолвера (`resolvectl flush-caches`).
- **Отслеживание состояния сети**:
  - Вместо постоянного 30-секундного таймера расширение подписано на события `Gio.NetworkMonitor` («network-changed»), минимизируя нагрузку на процессор и сеть.
- **Безопасность данных**:
  - Все операции записи конфигураций выполняются атомарно с блокировкой файлов (`flock`), исключая гонки и повреждение файлов.
  - Валидация входных имён: защита от некорректных символов, URL, поддержка кириллических IDN (punycode).

## Где хранятся данные

В соответствии со стандартом XDG:
- Конфигурации и список серверов: `~/.config/dns-switcher/dns_presets.json`
- Список целей проверки: `~/.config/dns-switcher/targets_list.txt`
- Текущее активное состояние и снимок: `~/.config/dns-switcher/current_dns.json`
- Кэш замеров задержки: `~/.cache/dns-switcher/cache_latencies.json`

Файл `dns_list.txt` в каталоге расширения используется только как стартовый шаблон для первоначального импорта серверов при самом первом запуске.

## Установка и запуск

### 1. Подключение расширения (символическая ссылка)

```bash
mkdir -p ~/.local/share/gnome-shell/extensions
ln -sfn ~/Applications/dns-switcher ~/.local/share/gnome-shell/extensions/dns-switcher@mcperchik
```

### 2. Включение расширения

```bash
gnome-extensions enable dns-switcher@mcperchik
```

Индикатор появится в системном трее верхней панели GNOME.

---

## Отключение и удаление

> **Важно**: Перед отключением или удалением расширения обязательно выберите пункт **«DNS по умолчанию»** в меню индикатора, чтобы вернуть сетевые настройки подключения к автоматическим! Параметры NetworkManager сохраняются на диске и не откатываются автоматически при отключении расширения.

### Временное отключение

```bash
gnome-extensions disable dns-switcher@mcperchik
```

### Полное удаление

```bash
gnome-extensions disable dns-switcher@mcperchik
rm -rf ~/.local/share/gnome-shell/extensions/dns-switcher@mcperchik
rm -rf ~/.config/dns-switcher ~/.cache/dns-switcher
```
